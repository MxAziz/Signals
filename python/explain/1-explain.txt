
EXPERIMENT 01: ELEMENTARY DISCRETE SIGNALS
------------------------------------------

QUESTION:
Explain and implement the following elementary discrete signals:
i) Unit sample sequence
ii) Unit step signal
iii) Unit ramp signal

Question-e ki chawa hoyeche:
Ekhane 3 ta basic discrete signal generate kore plot korte bola hoyeche.
Unit sample sudhu n=0 te 1 hobe.
Unit step n>=0 hole 1 hobe.
Unit ramp n>=0 hole n-er value nibe, ar n<0 hole 0 hobe.
-------------------------------------------------------------
LINE-BY-LINE EXPLANATION:

import numpy as np
→ Numpy numerical calculation korar jonno import kora hocche.

import matplotlib.pyplot as plt
→ Graph/plot draw korar jonno matplotlib import kora hocche.

n = np.arange(-10, 11)
→ -10 theke 10 porjonto discrete time index n create hocche.

unit_sample = np.where(n == 0, 1, 0)
→ Jekhane n=0, sekhane 1; baki sob position-e 0.
→ Eitai unit sample signal.

unit_step = np.where(n >= 0, 1, 0)
→ n 0 ba tar cheye boro hole 1, otherwise 0.
→ Eitai unit step.

unit_ramp = n * unit_step
→ Ramp signal-er jonno n ke unit step-er sathe multiply kora hocche.
→ Negative n-er khetre step=0, tai output-o 0.

plt.figure(figsize=(10, 8))
→ Graph window-er size set kora hocche.

plt.subplot(3, 1, 1)
→ 3 row-er moddhe first graph-er jayga select hocche.

plt.stem(n, unit_sample)
→ Unit sample-er discrete graph draw hocche.

plt.title(...)
→ Graph-er title set hocche.

plt.xlabel("n")
→ Horizontal axis-er label n.

plt.ylabel(...)
→ Vertical axis-er label set hocche.

plt.grid(True)
→ Graph-e grid dekhano hocche.

Porer subplot-gulo same way-te unit step ebong unit ramp plot korche.

plt.tight_layout()
→ Graph-gulor moddhe spacing automatically thik kore.

plt.show()
→ Final graph screen-e show kore.

------------------------------------------

QUESTION:

Question-e ki chawa hoyeche:
Given formula theke sequence-er prottek n-er value ber kore graph korte hobe.
delta[n+2] er impulse n=-2 te, ar delta[n-4] er impulse n=4 te.

→ Numerical calculation-er jonno numpy.

import matplotlib.pyplot as plt
→ Graph draw korar jonno matplotlib.

→ -7 theke +7 porjonto n create hocche.
→ Python-er arange-er last value include hoy na, tai 8 deya hoyeche.

delta_n_plus_2 = np.where(n == -2, 1, 0)
→ n=-2 hole impulse-er value 1, baki sob jaygay 0.

delta_n_minus_4 = np.where(n == 4, 1, 0)
→ n=4 hole impulse-er value 1.

x = 2 * delta_n_plus_2 - delta_n_minus_4
→ Question-er exact formula apply kora hocche.
→ n=-2 te value 2 ebong n=4 te value -1 pawa jabe.

print(...)
→ n ebong x[n]-er numerical value terminal-e dekhay.

plt.stem(n, x)
→ Discrete sequence-er stem graph draw kore.

plt.show()
→ Graph display kore.
